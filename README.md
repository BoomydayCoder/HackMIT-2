# rigor.ai

The Next.js starter for rigor.ai, an Olympiad practice app built for HackMIT.

## Run locally

Install Node.js 20.9 or later and pnpm 11. Then:

```bash
pnpm install
pnpm dev
```

Open http://localhost:3000.

## Checks

```bash
pnpm lint
pnpm typecheck
pnpm build
```

This starter contains only the App Router shell and landing page. Problem content, accounts, submissions, grading, and data storage have not been wired up yet.
